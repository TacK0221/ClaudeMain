# 点数計算ドリル

ランダムに出る和了形の点数を答えて、正解かどうかを判定する個人用の練習ツールです。
サーバーやDBは使わず、ブラウザだけで動きます（成績はそのブラウザに保存）。

## 使い方

- パソコン: `index.html` をブラウザで開くだけ
- スマホ: Netlify Drop（https://app.netlify.com/drop ）に `tensu` フォルダをドラッグして公開し、その URL を開く
  （スコア帳の `site` とは別のサイトとして公開します）

## 出題モード

| モード | 内容 |
|---|---|
| 実戦 | 実戦で多い手を多めに出す。満貫未満が6割強・立直4割・副露3.5割、待ちは両面が6割など |
| ランダム | 珍しい役・跳満以上・役満を多めに出す |
| 苦手 | 間違えたことのある分類（役・ツモ/ロン・親/子・符・打点）を優先して出す |

答え方は「点数だけ」と「翻・符も」を切り替えられます。

## ルール

喰いタンあり・赤ドラあり・切り上げ満貫あり・数え役満あり・連風牌の雀頭は4符・ダブル役満なし・本場/供託なし。
`mahjong.js` の先頭にある `RULES` で変更できます（連風牌を2符にするなら `doubleWindPairFu: 2`）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `mahjong.js` | 牌姿の生成と点数計算。出題の重み（`PRACTICAL` / `RANDOM`）もここ |
| `test.js` | 点数計算のテストと、生成した問題の分布の確認。`node tensu/test.js` で実行 |

点数計算は、Python の点数計算ライブラリ `mahjong`（天鳳ルール準拠）と同じルール設定で、生成した30,000問の結果が一致することを確認しています。
