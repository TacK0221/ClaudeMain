# 点数計算ドリル

ランダムに出る和了形の点数を答えて、正解かどうかを判定する個人用の練習ツールです。
サーバーやDBは使わず、ブラウザだけで動きます（成績はそのブラウザに保存）。

## 使い方

- パソコン: `index.html` をブラウザで開くだけ
- スマホ: Netlify Drop（https://app.netlify.com/drop ）に `tensu` フォルダをドラッグして公開し、その URL を開く
  （スコア帳の `site` とは別のサイトとして公開します）

## 出題モード

符の計算を練習するためのツールなので、出題は4翻以下（符で点数が変わる手）だけです。役満・5翻以上は出ません。

| モード | 内容 |
|---|---|
| 実戦 | 実戦で多い手（立直・平和・タンヤオ・役牌）。30符・40符が中心で、待ちは両面が6割など |
| 符いろいろ | 刻子・槓子・嵌張/辺張/単騎を多めにして、20符〜80符以上まで満遍なく出す |
| 苦手 | 間違えたことのある分類（暗刻・明刻・么九牌の刻子・槓子・役牌の雀頭・嵌張/辺張/単騎・シャンポンのロン・平和ツモ・七対子・◯符など）を優先して出す |

答えは点数で入力します。「親・子」で、子だけ・親だけ・両方のどれを出題するか選べます。答え合わせのあとに符の内訳（どこで何符付いたか）を表示します。

## ルール

喰いタンあり・赤ドラあり・切り上げ満貫あり・連風牌の雀頭は4符・本場/供託なし。
`mahjong.js` の先頭にある `RULES` で変更できます（連風牌を2符にするなら `doubleWindPairFu: 2`）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `mahjong.js` | 牌姿の生成と点数計算。出題の重み（`PRACTICAL` / `FU`）もここ |
| `tiles.js` | 牌の絵柄（SVG）。萬子・筒子・索子・字牌 |
| `test.js` | 点数計算のテストと、生成した問題の分布の確認。`node tensu/test.js` で実行 |

点数計算は、Python の点数計算ライブラリ `mahjong`（天鳳ルール準拠）と同じルール設定で、生成した問題（実戦・符いろいろ 各10,000問）の結果が一致することを確認しています。
