# 点数計算ドリル

ランダムに出る和了形の点数を答えて、正解かどうかを判定する個人用の練習ツールです。
サーバーやDBは使わず、ブラウザだけで動きます（成績はそのブラウザに保存）。

## 使い方

- パソコン: `index.html` をブラウザで開くだけ
- スマホ: Netlify Drop（https://app.netlify.com/drop ）に `tensu` フォルダをドラッグして公開し、その URL を開く
  （スコア帳の `site` とは別のサイトとして公開します）

## 出題

実戦でよく出る手（立直・平和・タンヤオ・役牌）から出題します。30符・40符が中心で、待ちは両面が6割ほどです。
符の計算を練習するためのツールなので、9割は4翻以下（符で点数が変わる手）、1割は5翻以上（満貫・跳満・倍満など）です。役満は出ません。

- 答えは点数を4択で選びます。間違いの選択肢は、符を10符ずらす・翻を1つずらす・切り上げ満貫を忘れる・親子を取り違えるといった、よくある間違い方で計算した点数です
- 「親・子」で、子だけ・親だけ・両方のどれを出題するか選べます
- 答え合わせのあとに符の内訳（どこで何符付いたか）・役・計算の流れを表示します
- 成績と、間違えやすい分類（暗刻・么九牌の刻子・嵌張/辺張/単騎・シャンポンのロンなど）はブラウザに保存します

## ルール

喰いタンあり・赤ドラあり・切り上げ満貫あり・連風牌の雀頭は4符・本場/供託なし。
`mahjong.js` の先頭にある `RULES` で変更できます（連風牌を2符にするなら `doubleWindPairFu: 2`）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `mahjong.js` | 牌姿の生成・点数計算・4択の選択肢。出題の重み（`PRACTICAL`）と5翻以上の割合（`HIGH_RATE`）もここ |
| `tiles.js` | 牌の絵柄（SVG）。萬子・筒子・索子・字牌 |
| `test.js` | 点数計算のテストと、生成した問題の分布の確認。`node tensu/test.js` で実行 |

点数計算は、Python の点数計算ライブラリ `mahjong`（天鳳ルール準拠）と同じルール設定で、生成した問題の結果が一致することを確認しています。
