各版のファイルは `backup/v1.0/`、`backup/v1.1/`、`backup/v2.0/`、`backup/v2.1/` に保存しています（公開するのは `site` フォルダだけ）。

### Ver2.1 をデプロイするとき
1. Firebase コンソール →「Firestore」→「ルール」タブを開き、`firestore.rules` の中身を全部貼り付けて「公開」
2. そのあとで Netlify に `site` フォルダをデプロイ
（ルールを先に更新しないと、チップの記録が保存・表示されません。画面上部にその旨の案内が出ます）
不具合が出たときは、`backup` の前の版の `index.html` を `site` に上書きしてデプロイすれば元に戻せます。

友達もアカウント無しで、スマホのブラウザから URL を開くだけで入力・閲覧できるようにする手順です。
費用はすべて無料枠で収まります（友達同士の利用量なら上限に届きません）。

## 1. Firebase プロジェクトを作る（DB）

1. https://console.firebase.google.com/ を開き、Google アカウントでログイン
2. 「プロジェクトを作成」→ 名前は例えば `mahjong-score`。Google アナリティクスはオフで OK
3. 左メニュー「Database と Storage」→「Firestore」→「データベースを作成」
   （見当たらなければ左上の「商品を検索」で「Firestore」と検索）
   - エディションを聞かれたら「Standard」
   - データベースIDは `(default)` のまま
   - ロケーション: `asia-northeast1 (Tokyo)`
   - 「本番環境モード」で開始
4. Firestore の「ルール」タブを開き、このフォルダの `firestore.rules` の中身をそのまま貼り付けて「公開」
   - 「誰でも読み書きできる」という警告が出ますが、そういう設定にしているので問題ありません

## 2. 画面に Firebase の設定を入れる

1. Firebase コンソールの「プロジェクトの概要」横の歯車 →「プロジェクトの設定」
2. 「マイアプリ」で `</>`（ウェブ）を選び、アプリ名を入れて登録（Hosting のチェックは不要）
3. 表示される `firebaseConfig = { apiKey: ..., ... }` の値を、
   `site/index.html` の上の方にある `FIREBASE_CONFIG` の各項目にコピーする

```js
const FIREBASE_CONFIG={
  apiKey:"AIza....",
  authDomain:"mahjong-score-xxxx.firebaseapp.com",
  projectId:"mahjong-score-xxxx",
  storageBucket:"mahjong-score-xxxx.appspot.com",
  messagingSenderId:"1234567890",
  appId:"1:1234567890:web:abcdef"
};
```

この値はサイトを見れば誰でも分かるもので、公開して問題ありません。

## 3. Netlify で公開する

1. https://app.netlify.com/drop を開く
2. `site` フォルダをドラッグ＆ドロップ
3. 表示された URL（`https://xxxx.netlify.app`）がスコア帳の URL です
   - 一時公開のままだと消えるので、案内に従って無料アカウントを作り、サイトを残してください
   - サイト名は「Site configuration → Change site name」で `mahjong-xxxx` のように変えられます

画面を直したときは、同じサイトの「Deploys」画面に再び `site` フォルダをドラッグすると更新されます。

## 4. 友達に共有する

- URL を送るだけです。開けばすぐ入力・閲覧できます
- スマホではブラウザの「ホーム画面に追加」でアプリのように使えます

## データの構成（Firestore）

```
members/{ユーザーID}   { userId: "U001", userName: "たかや" }
games/{対局ID}         { gameId: 12, mode: 4, date: "2026-10-05",
                         results: [ { seat: "東", userId: "U001", rawScore: 42300, score: 53 }, ...4人 ] }
                       ※mode は 4（4人麻雀）か 3（3人麻雀、results は3人分）。mode の無い古い対局は4麻
                       ※記録帳で入力した対局は seat と rawScore が null
chips/{精算ID}         { chipId: 3, mode: 4, date: "2026-10-06",
                         results: [ { userId: "U001", chips: 12 }, ...3人以上 ] }   ← 換算ptは保存しない（1枚 = 2pt で表示時に計算）
meta/counters          { lastGameId: 12, lastUserId: 4, lastChipId: 3 }   ← 連番の採番用
```
